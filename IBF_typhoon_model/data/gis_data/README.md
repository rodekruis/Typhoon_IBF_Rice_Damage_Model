
## gis_data

find_enter_exit_per_municipality.py contains the code used to get the enter and exit times per municipality and typhoon combination (for the extent based rainfall variables). Its output is typhoon_enter_exit_per_municipality.csv
The verification_functions.ipynb notebook contains three codeblocks
1. Verifying find_enter_exit_per_municipality.py output
2. Verifying how well the extents match the damage data
3. Statistical analysis on the time difference between enter and exit times calculated with find_enter_exit_per_municipality.py
